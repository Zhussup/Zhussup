### Featured Project

**[ProteinGPU-Studio](https://github.com/Zhussup/ProteinGPU-Studio)** — in-silico protein mutagenesis with real structure prediction (OmegaFold / ESMFold) and honest CPU vs GPU benchmarks.
Web platform (FastAPI + React/TypeScript) with an HPC core in **C++17 / CUDA** exposed via pybind11: wild-type vs mutant structure comparison (RMSD, TM-score, pLDDT), and a Kabsch/RMSD kernel implemented three ways (NumPy, C++ OpenMP, CUDA — ~88× faster than NumPy on batches).
